# External pilot dry run (2026-10-10)

A simulated partner handoff, run end to end from **outside the repository working tree**
(`<workspace>/outputs/external_dry_run_20261010/`) with public data only. No real partner, no
PHI, and no human review recorded. Script: `run_dry_run.sh` and `make_transfer.py` in that
folder; full log `dry_run.log`.

## Environment

VoxelTrace 0.4.0 at commit `8b6443f` (clean tree; deployment lock captured and verified =
LOCK_MATCH), Python 3.12.3, x86_64 (AMD Ryzen 9 9950X), CPU only.

## Simulated partner side

The transfer `TRANSFER-SIM/` contains the simulated multi-site drop built from the public
cohort (`scripts/make_partner_drop.py`): 3 sites, 8 subjects, irregular visit names (`Baseline/
Follow-Up`, `pre/post`, `BL/FU1`), a PDF placeholder, a JSON sidecar, notes, `.DS_Store`,
`__MACOSX/`, a non-attenuation-corrected copy and a second attenuation-corrected reconstruction.
It also holds a `partner_intake.yaml` (16 entries, VT-PARTNER-INTAKE-1) and `SHA256SUMS.txt`.

## Lessons

1. The nested-drop route (`validate-input` → `intake-map`) worked without code changes;
   the only human step was the expected series question.
2. `deployment-lock capture` into a non-existent folder crashed; fixed (parent created).
3. Total operator time for a clean 8-pair drop: about 4 minutes of compute plus the time to
   answer one intake question.
