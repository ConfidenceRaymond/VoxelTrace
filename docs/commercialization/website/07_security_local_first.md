# Website page: Security / Local-First

**Headline:** Your data stay where you put them

**Subhead:** The audit runs offline on a machine you control.

## Sections

- No cloud processing; no network calls during the audit.
- Inputs are read-only; outputs contain no images.
- Every delivery is checksummed and pattern-scanned for identifiers and paths.
- De-identification remains the data owner's responsibility.

**CTA:** Ask for the data-handling checklist

**Validation note (shown on the page):** Research and trial-QC software, not for clinical use. External expert validation is pending. Siemens scanners validated on real public longitudinal pairs; GE ingestion only; Philips metadata only.

## Claims allowed now

- runs offline
- no images in deliverables
- privacy scan is a safety net, not de-identification

## Claims NOT allowed now

- clinically validated
- FDA / Health Canada / CE / EU MDR approved, cleared or compliant
- diagnoses, stages or classifies treatment response
- validated for all vendors
- guarantees comparability
- guarantees cost savings or regulator acceptance
- AI-powered / uses AI to decide
