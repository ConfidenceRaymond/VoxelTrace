# Website page: Product

**Headline:** The Retrospective PET Comparability Audit

**Subhead:** Intake, preflight, comparability rules, evidence trace, delivery.

## Sections

- Intake: maps partner folders, selects the PET series only by explicit rules, and holds ambiguity for review.
- Preflight: can each scan be quantified as exported?
- Comparability: four verdicts per pair and rule set (ASSESSABLE, ASSESSABLE_WITH_WARNINGS, NOT_ASSESSABLE, INSUFFICIENT_INFORMATION).
- Evidence: rule → field → value → trust level → source, for every pair.
- Delivery: sanitized, checksummed package with methodology and limitations.

**Validation note (shown on the page):** Research and trial-QC software, not for clinical use. External expert validation is pending. Siemens scanners validated on real public longitudinal pairs; GE ingestion only; Philips metadata only.

## Claims allowed now

- deterministic: same data and version, same result
- versioned rule sets
- verifiable with sha256sum

## Claims NOT allowed now

- clinically validated
- FDA / Health Canada / CE / EU MDR approved, cleared or compliant
- diagnoses, stages or classifies treatment response
- validated for all vendors
- guarantees comparability
- guarantees cost savings or regulator acceptance
- AI-powered / uses AI to decide
