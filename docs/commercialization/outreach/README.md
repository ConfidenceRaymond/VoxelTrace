# Outreach asset pack

Templates for first contact and follow-up. Replace every `<...>`. Lead with quantitative PET
comparability, auditability, provenance, site/scanner consistency and trial QC. **Do not pitch
AI** (the audit uses none).

**Never claim:** clinical validation; regulatory approval or clearance; complete multi-vendor
validation; external expert agreement (pending); guaranteed savings; guaranteed trial or
regulator acceptance. **Always state** when relevant: research/trial-QC software, external
validation pending, Siemens validated on public pairs, GE/Philips limited.
