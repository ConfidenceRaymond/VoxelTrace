# What you receive (one page)

A delivery package of derived outputs only (no images, no identifiers), verifiable with
`sha256sum`:

- **One-page executive summary (PDF):** how many scans can be quantified, how many pairs are
  comparable under QIBA FDG 1.14, EANM FDG 2.0 and PERCIST 1.0, top issues, sites requiring
  action, what is waiting for human review.
- **Pair table:** every pair and rule set: ASSESSABLE, ASSESSABLE_WITH_WARNINGS,
  NOT_ASSESSABLE or INSUFFICIENT_INFORMATION, with plain-language reasons.
- **"Why" trace per pair:** rule → DICOM field → value at both visits → trust level → source.
- **Site/scanner summary and protocol drift.**
- **Unresolved items and draft site queries** (you edit and send them; we send nothing).
- **Remediation table:** what each finding means and whether a re-export, site records or a
  review can fix it.
- **Checksummed evidence bundle and methodology/limitations note.**

What it is not: not a diagnosis, not treatment-response assessment, not a medical device, not
yet externally validated.
