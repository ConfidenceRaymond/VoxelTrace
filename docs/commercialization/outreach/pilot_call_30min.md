# 30-minute pilot scoping call

Goal: agree whether and how a free retrospective pilot could run. Outcome: a draft
`../../pilot/external_partner/PILOT_SCOPE_TEMPLATE.md`.

| Min | Topic |
|---|---|
| 0–3 | Purpose and status: research/trial-QC software; external validation pending; what it does not do |
| 3–8 | 5-minute demo on sanitized data (`../../demo/demo_runbook.md`) |
| 8–15 | Dataset: study, subjects, timepoints, tracer (FDG), vendors/models, sites; de-identification route |
| 15–20 | Data handling: DUA, transfer, retention/deletion (`TRANSFER_CHECKLIST.md`) |
| 20–25 | People: data contact; PET physicist for reference-region, lesion and TEXT_IMPLIED review |
| 25–30 | Success criteria (`../../pilot/pilot_success_scorecard.md`), timeline, next step |

Do not discuss prices unless asked; if asked, say pricing is being set from pilot evidence.
