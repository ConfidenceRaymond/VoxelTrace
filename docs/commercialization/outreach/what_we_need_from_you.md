# What we need from you (one page)

**Data (de-identified, minimum necessary)**
- One attenuation-corrected FDG PET series per visit (DICOM, Units BQML), baseline and follow-up.
- The CT acquired with each PET, if PERCIST is in scope.
- A visit list: subject pseudonym, visit, site. No names, MRNs, accession numbers or birth dates.
- Kept in the DICOM: injected activity and injection time, weight (height and sex for PERCIST),
  scanner/model/software, reconstruction description.
- Optional: lesion segmentations; site reconstruction protocol sheets.

**Agreements**
- A data-use agreement and a signed pilot scope before any transfer.

**People**
- A data contact for intake questions.
- A PET physicist (or nuclear-medicine physician) for reference-region, lesion and
  reconstruction-evidence review (about `<n>` hours, measured in the pilot).

Details: `DATA_REQUIREMENTS.md`, `TRANSFER_CHECKLIST.md`, `partner_intake.yaml`.
