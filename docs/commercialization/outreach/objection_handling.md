# Objection handling (honest answers)

| Objection | Answer (do not overclaim) |
|---|---|
| "Our physicists already check this." | Then their view is exactly what we need. VoxelTrace makes the check explicit, per pair, with the DICOM evidence, so it can be repeated and audited; it does not replace their judgement. |
| "Is it validated?" | Deterministic tests and a reproducible audit of 9 real public pairs, yes. Independent expert validation is pending; your physicist's review in a pilot is part of it. |
| "We use GE / Philips." | Today, Siemens is validated on public pairs; GE is validated for ingestion only and Philips for metadata only. Expect more "insufficient information"; a pilot (or a phantom) is how that changes. We will not relax the checks to make them pass. |
| "Is this AI?" | No. The audit is rule-based and deterministic; no model makes any measurement or decision. |
| "Is it a medical device / FDA cleared?" | It is research and trial-QC software, not for clinical use, with no regulatory clearance. |
| "We can't send data." | The audit runs offline; it can be installed locally under your control. A data-use agreement is required either way. |
| "Too many 'insufficient information' results." | Each one names the missing evidence and whether a re-export, site records or a review can resolve it. Missing evidence is never treated as a pass. |
| "What does it cost?" | The first pilot is unpaid; pricing will be set from pilot evidence. No number is quoted yet. |
| "Will it save us money?" | We do not know yet; a pilot measures review time before and after. No savings are guaranteed. |
| "Will regulators accept this?" | Not claimed. It produces an audit trail that may support your own QC documentation. |
