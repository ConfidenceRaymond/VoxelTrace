# 15-minute discovery call

Goal: learn, not pitch. Use `../interview_scoring_rubric.md` afterwards.

| Min | Topic | Questions |
|---|---|---|
| 0–2 | Context | role, studies, PET volume, sites/scanners |
| 2–7 | Current workflow | Who checks comparability of timepoints? How (tools, spreadsheets, by eye)? How long per pair? |
| 7–11 | Last problem | Most recent non-comparable pair or site query: what, when, cost, how found? |
| 11–13 | Buying | Who would decide on a QC tool or service, from which budget? |
| 13–15 | Next step | Would a retrospective audit of a de-identified dataset be useful? Who else should I talk to? |

Only if asked "what are you building?": one sentence, no AI, mention research status and
pending validation.
