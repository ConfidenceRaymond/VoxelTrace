# Pilot success metrics (defined before a pilot; none measured on sponsor data yet)

| Metric | Definition |
|---|---|
| % READY_TO_QUANTIFY | scans with preflight READY_TO_QUANTIFY / all scans |
| % pairs assessable | ASSESSABLE + ASSESSABLE_WITH_WARNINGS per rule set |
| % NOT_ASSESSABLE | pairs with a decided blocking failure |
| % INSUFFICIENT_INFORMATION | pairs that cannot be decided, with reason distribution |
| Top failure causes | reason-code counts (e.g. AMBIGUOUS_RECONSTRUCTION, DECAY_FACTOR_INCONSISTENT) |
| Site drift events | per site and type (software, reconstruction, filter, voxel) |
| Previously unknown QC findings | findings the partner did not know before the audit (partner-confirmed) |
| Review time | reference-region and adjudication minutes per pair |
| Expert agreement | BLINDED package: agreement, κ, **false-safe rate** (must be explained if > 0) |

**Not metrics:** willingness to pay, pricing and regulatory status are not claimed or
measured here.
